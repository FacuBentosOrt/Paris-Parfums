# Paris Parfums React

Proyecto React basado en la ultima maqueta noir.

## Incluye

- Landing principal con hero y catalogo en la misma pagina
- Animaciones de aparicion al hacer scroll
- Ruta de detalle por perfume en `/perfumes/:slug`
- CSS separado en `src/styles/global.css` y `src/styles/app.css`

## Comandos

```bash
npm install
npm run dev
```
